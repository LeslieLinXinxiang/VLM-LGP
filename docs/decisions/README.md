# Decision Docs

This folder stores project decision artifacts.

## Contents
- `DDR_TEMPLATE.md`: template for new decision records.
- `DDR-YYYYMMDD-<topic>.md`: approved decision records.
- `DDR-20260313-waypoint-gated-constraint-reachability.md`: decision to use waypoint data as shared gate for reachability pre-check and active collision constraint selection.

## Scope Note
`DDR_TEMPLATE.md` here is the project-local working instance.
Reusable source template can exist in skill roots (for example `dde-ext-brainstorm/templates/DDR_TEMPLATE.md`).
When both exist, use the project-local instance in this folder.
